## Projeto Grafo Teste

### **Descrição**

#### Para utilizar o *software* execute o arquivo, presente em *src/grafos/Interface/*, *InterfaceDeConfiguração*. Neste você poderá especificar
#### * O tipo de Representação (Matriz de Adjacência, Incidência ou Lista de Adjacência)
#### * O arquivo contendo o grafo (Arquivo exemplo dentro de *src/grafos.arquivos_de_teste* - O padrão deve ser mantido)

#### Image
![Image 1](GrafosTeste/SampleImage/img1.png)

#### Após a configuração do grafo ser definida, escolha o algoritmo que se deseja aplicar no grafo! A saída conterá o resultado do algoritmo junto ao seu tempo de execução calculado pelo *Chronometer.java*
